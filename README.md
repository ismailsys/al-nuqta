# AL-NUQTA

Application web de récitation et de recentrage spirituel. Stack : React, TypeScript et Vite. Déploiement prévu sur Cloudflare Pages (build `npm run build`, dossier `dist`).

Le contenu coranique et les traductions doivent être vérifiés avant toute publication. L'application propose un accompagnement spirituel et pédagogique, sans prétention médicale.
